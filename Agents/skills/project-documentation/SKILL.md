# Project Documentation

- Treat supplied requirements, design, source code, test results, and review results as the only sources of truth.
- Distinguish implemented behavior from planned or unspecified behavior.
- Preserve exact commands, public interfaces, and status information from the supplied artifacts.
- Do not claim tests passed, features exist, or integrations are configured unless the evidence says so.
