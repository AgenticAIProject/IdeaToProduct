# Code Generation

- Treat the approved requirements and design as authoritative. Do not invent features or change technology choices.
- Keep implementation focused on the requested file and its stated responsibility.
- Match public names and interfaces from the plan exactly so generated files work together.
- Prefer complete, runnable implementations with explicit input validation and sensible error handling.
- Do not add dependencies, files, or architecture that the design does not need.
