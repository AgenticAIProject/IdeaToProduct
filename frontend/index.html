01

Requirements

Converts ideas into user stories, functional requirements, acceptance criteria, and scope boundaries.

INPUTRaw product idea
PROCESSUser stories · Scope · Acceptance criteria
OUTPUTRequirements artifact
02

Design

Produces architecture decisions, component diagrams, data models, and API surface definitions.

INPUTRequirements
PROCESSArchitecture · Components · APIs · Data models
OUTPUTDesign artifact
03

Code

Scaffolds the repository and generates working source files using claude-sonnet-4-6.

INPUTDesign artifact
PROCESSRepository scaffold · Source files · Dependencies
OUTPUTWorking project on disk
04

Tests

Executes pytest against the generated project. Returns real pass/fail counts from actual execution.

INPUTGenerated project
PROCESSpytest execution · Coverage · Error capture
OUTPUTPass / Fail / Error counts
05

Review

Hard quality gate. Independently evaluates consistency across all stages. Can trigger a rework cycle.

INPUTAll prior artifacts
PROCESSCross-stage consistency · Security · Quality
OUTPUTApproved or rework required
06

Documentation

Generates user-facing and developer documentation from approved, reviewed artifacts.

INPUTApproved artifacts
PROCESSREADME · API docs · Architecture · Setup
OUTPUTDocumentation artifact
